Turn **ChatGPT** - or another capable AI assistant - into a personalized F1 Clash racing strategist using **your actual Drivers, Components, Boosts, event screenshots, tyre information, and race results**.

## What makes this different

The AI is instructed to:

- Use **your verified account inventory**, not generic card rankings.
- Never pretend it inspected a screenshot, spreadsheet, ZIP member, or webpage it did not actually access.
- Let newer item-specific evidence update **only that item**, instead of silently rewriting the rest of your inventory.
- Keep permanent baseline stats separate from temporary Grand Prix bonuses.
- Give a **NEED TO WIN** Boost and an **ECONOMY** Boost for each Driver.
- Use race results as evidence without overreacting to one race.
- Prefer current official Hutch information when game mechanics or event rules may have changed.

## Important privacy / sharing rule

This public repository contains the **system and blank templates only**. Each player should keep their own Driver, Component, Boost, and account screenshots in their own private AI project/workspace. Do not put multiple clan members' live inventories into one shared knowledge base.
